Application web de covoiturage développée avec Java Enterprise Edition (JEE), JSP, Servlets et MySQL.

## 📋 Fonctionnalités

- ✅ **Inscription/Connexion** des utilisateurs
- ✅ **Gestion des rôles** (Conducteur/Passager)
- ✅ **Publication de trajets**
- ✅ **Recherche et réservation**
- ✅ **Système de notation**
- ✅ **Tableau de bord personnalisé**

## 🛠 Technologies

- **Backend** : Java EE (Servlets, JSP, JDBC)
- **Frontend** : HTML5, CSS3, JavaScript, Bootstrap
- **Base de données** : MySQL 8.0
- **Serveur** : Apache Tomcat 9.0
- **Outils** : Maven, Eclipse IDE
